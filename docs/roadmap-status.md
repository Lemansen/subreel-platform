### 11. Плеер — В работе
- `/watch/[slug]` загружает только источники, которые прошли RLS: published, approved, available и привязаны к опубликованному тайтлу/серии. Подключены HTML5 MP4, HLS через hls.js с native fallback, DASH через dash.js и sandboxed embed для HTTPS URL форматов YouTube NoCookie `/embed/{id}`, Vimeo `/video/{id}` и RuTube `/play/embed/{32 hex ID}` с необязательным завершающим слешем. RuTube iframe получает clipboard-write и autoplay permissions; редактор принимает только точные домены и формат embed URL. Для embed прогресс не синхронизируется. Качество/аудиодорожки/субтитры и автопереход не реализованы; реальные источники ещё не проверены.

Очередь видна в журнале; активные задания можно продолжить после закрытия страницы. Миграция `026_catalog_import_queue.sql` применена, подтверждены новая запись миграции, поля очереди и сохранение RLS на таблице заданий.

Если Supabase не смог сохранить ошибку строки, курсор не двигается, задание возвращается в очередь (либо освобождается по окончании аренды), чтобы строка не пропала без записи.

Ежедневное расписание выбрано для совместимости с Hobby-планом Vercel; лимиты и точность расписания зависят от плана.
